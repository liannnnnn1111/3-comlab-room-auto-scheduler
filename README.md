# 🗓️ 3-ComLab Room Auto-Scheduler

An automated scheduling system built for managing the availability and usage of **three computer laboratories** (ComLab1, ComLab2, ComLab3) in an academic setup.

## 🎯 Purpose

Designed to eliminate scheduling conflicts for admins when assigning lab times across **different year levels, subjects, and units**. This system **automatically generates lab schedules** based on the admin's input — ensuring efficient, conflict-free booking.

## 🛠️ Tech Stack

- 🐘 **PHP** – backend logic and scheduling engine  
- 🎨 **Bootstrap** – responsive and clean user interface  
- 💻 **HTML / CSS / JavaScript** – dynamic interaction and form control

## 🚀 Key Features

- 🔁 Automatic subject scheduling per ComLab
- 🧠 Collision detection based on subject, year level, and unit
- 📋 Admin input triggers auto-generation of schedule
- 📱 Mobile-friendly UI using Bootstrap

## 📌 How It Works

1. Admin enters:
   - Subject name
   - Year level
   - Number of units
2. System checks availability across all 3 labs
3. Automatically assigns a time slot in the **first available lab**
4. Prevents conflicts across all labs for the same timeslot/year level

## 🏫 Target Use Case

Perfect for schools or universities managing multiple computer labs, where scheduling coordination across subjects and departments is a challenge.
